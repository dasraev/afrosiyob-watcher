# Afrosiyob seat watcher

Checks every 30 s for free seats on any Afrosiyob train Navoiy → Toshkent on 8–9 Oct 2026
and sends a Telegram message. Runs on GitHub Actions.

Secrets: `TG_TOKEN` (bot token), `TG_CHAT_ID` (your chat id).
Stop it: Actions → "Afrosiyob seat watcher" → ⋯ → Disable workflow.
